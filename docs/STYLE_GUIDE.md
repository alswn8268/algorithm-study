# 🖍️ 디자인 고정 규칙 — 볼펜 발그림 스타일 (32컷 전체 통일)

이 문서는 이 프로젝트가 생성하는 32컷 전체에 적용되는 **화풍 고정 규칙**입니다.
코드상으로는 `prompts.py`의 `pen_doodle` 프리셋(기본값)이 이 규칙을 인코딩합니다.

참고 화풍은 "대충 그린 정제되지 않은 낙서" 계열입니다.
**화풍의 문법만 가져오고 실루엣·포즈·컨셉은 오리지널로** 만들어야 합니다 —
특정 캐릭터와 닮으면 심사 탈락 사유입니다.

> 그래서 참고 작가/캐릭터의 **이름은 프롬프트에 절대 넣지 않습니다.**
> `copyright_guard.py`의 `STYLE_REFERENCE_BLOCKLIST`가 이를 강제로 차단합니다.
> 화풍은 이름이 아니라 아래의 서술(선·눈·비율·채색)로만 재현하세요.

---

## 1. 고정 규칙 4가지

| 요소 | 규칙 |
| --- | --- |
| **눈** | **초롱초롱(sparkle)** = 큰 눈망울 + 큼직한 하이라이트, **광기(manic)** = 흰자를 벌리고 작은 동공을 제멋대로. [하이라이트가 크고 많을수록 귀엽고 흥분해 보인다](https://www.clipstudio.net/drawing/archives/162865)는 게 작동 원리다 |
| **색** | 이목구비를 새까맣게 찍지 않고 갈색 계열로 풀어준다. 하트·물방울·반짝임은 **색을 넣어야** 눈에 들어온다 |
| **팔다리** | 직선이면 막대기처럼 뻣뻣하다. **휜 뼈대에 살을 붙여** 자연스럽게 굽게 한다 (귀·꼬리도 동일) |
| **중안부** | 눈과 입 사이를 **일부러 멀리 벌린다.** 코와 입이 아래쪽에 모이고 눈은 위에 — 이 간격이 현재 트렌드의 핵심 매력 포인트다 |
| **형태** | **큰 머리 + 작은 몸통**이 겹친 구조. 통짜 원 하나면 감자에 혹이 붙은 모양이 되고 동물로 읽히지 않는다 |
| **선** | 바깥 윤곽은 **실루엣 하나로 이어** 긋고, 귀·팔다리는 **안쪽 구분선 + 한 톤 낮춘 평면 명암**으로 나눈다. 몸에 가려지는 부분은 그리지 않는다 — 안 그리면 팔다리가 몸을 투과해 보인다 |
| **비율** | 좌우를 살짝 다르게. **다만 과하게 일그러뜨리지 않는다** — 형태가 무너지면 동물로 안 보인다 |
| **채색** | **깔끔한 평면 채색.** 흰/크림색 몸이 주류(＝낙서형 흰둥이). 그라데이션·명암 **절대 금지** |

> 📌 **규칙 변경 이력**
> 1. 초기: "큰 점눈 + 선 밖으로 삐져나간 채색 + 찌그러진 형태"
> 2. 트렌드 조사 후: **작은 눈 + 깔끔한 평면 채색** (삐져나간 채색은 실제로
>    렌더해 보면 지저분하고, 큰 점눈은 현재 인기 캐릭터 문법과 어긋남)
> 3. 실물 검토 후: **머리/몸통 분리 + 부품 명암 + 왜곡 축소**
>    — 실루엣을 하나로만 합치니 부품 구분이 사라져 감자처럼 보였고,
>    왜곡이 과해 동물로 읽히지 않았음
> 4. 표정 강화: **초롱초롱/광기 눈 + 이목구비·표현 채색 + 곡선 팔다리**
>    — 작은 점눈은 표정이 안 살고, 검은 선만으로는 하트·눈물이 안 읽히고,
>    직선 팔다리는 뻣뻣했음. (눈 크기 규칙이 2번에서 다시 뒤집힌 지점)

## 2. ⚠️ 시작 전 꼭 읽기 (3가지)

### 1) 한글 텍스트는 AI에 시키지 마세요

이미지 생성 AI는 한글을 거의 항상 깨뜨립니다. **그림만 뽑고**, 텍스트는 나중에
프로크리에이트/포토샵/클립스튜디오에서 손글씨 폰트로 직접 얹으세요.
**흰색 아웃라인 필수** — 다크모드 대응입니다.

이 원칙은 코드에도 반영돼 있습니다:

- 모든 네거티브 프롬프트에 `text, letters, words, korean text, hangul, caption`이 들어갑니다.
- `text_based` 프리셋은 문구를 그리게 하는 대신 **하단에 빈 공간만** 확보합니다.
- `quality.py`의 `check_dark_mode_legibility`가 어두운 배경에서 묻히는 컷을
  자동으로 `needs_review`로 보냅니다.

### 2) 캐릭터 일관성

- **미드저니**: 마음에 드는 첫 컷을 뽑은 뒤 `--cref [이미지URL] --cw 100`으로
  나머지 컷을 뽑으면 얼굴이 유지됩니다.
- **ChatGPT 이미지**: 첫 컷 생성 후 같은 대화에서 "같은 캐릭터로 다음 포즈"라고
  이어가면 됩니다.
- **이 저장소의 `stable_diffusion` 백엔드**: `--seed`를 고정하면 컷마다
  `base_seed + i`로 파생돼 톤이 비교적 안정됩니다. 다만 seed만으로는 얼굴
  일관성이 완벽하게 유지되지 않으므로, 본격 작업에는 위의 `--cref` 방식이나
  LoRA 학습을 권장합니다.

### 3) AI 티 제거 후처리

뽑은 이미지를 **그대로 제출하지 마세요.** 완벽한 대칭과 균일한 선이 AI 티의 주범입니다.

1. 선을 따라 직접 다시 그리거나(**트레이싱**), 또는
2. 최소한 좌우 비대칭·선 굵기 요동을 손으로 추가하세요.

`postprocess.add_hand_jitter()`가 저주파 변위장으로 선을 미세하게 흔들어
균일함을 깨뜨립니다 (`--jitter` 옵션, 기본 1.5). 다만 이건 **보조 수단**입니다.
"겹쳐 그은 획"이나 "끝에서 안 만나는 선" 같은 이 화풍의 본질은 픽셀 변형으로는
만들어지지 않습니다.

## 1-1. 동물형 캐릭터 — 종을 알아보게 하는 것들

인기 이모티콘은 대부분 **동물형**입니다(곰·토끼·강아지·햄스터·오리). 종을
알아보게 만드는 건 결국 몇 가지 부품의 조합이고, 이 저장소는 그 **구조 문법**만
가져옵니다.

| 종 | 귀 | 코 | 그 외 |
| --- | --- | --- | --- |
| `bear` 곰 | 큼직한 반원 | 검은 점 | 주둥이, 꼬리 |
| `hamster` 햄스터 | 작고 동그란 귀 | 검은 점 | **볼주머니**, 수염, **앞니** |
| `rabbit` 토끼 | 길쭉한 귀 | 삼각 | 주둥이, 앞니 |
| `cat` 고양이 | 삼각 귀 | 삼각 | 수염, 말린 꼬리 |
| `dog` 강아지 | 축 늘어진 귀 | 큰 점 | 주둥이, 말린 꼬리 |
| `duck` 오리 | 없음 | **부리**(입 겸용) | — |
| `seal` 물범 | 없음 | 검은 점 | 주둥이, 수염, 옆으로 퍼진 몸 |
| `guineapig` 기니피그 | 꽃잎(머리 옆 낮게) | 갈색 점 | 목 없는 낮고 넓은 몸, 앞니, 수염, **털 얼룩**, 꼬리 없음 |

> ⚠️ **특정 캐릭터를 참고할 땐 이름을 프롬프트에 절대 넣지 마세요.**
> 이름을 넣으면 화풍만이 아니라 실루엣까지 따라가 심사 탈락 사유가 됩니다.
> `copyright_guard.STYLE_REFERENCE_BLOCKLIST`가 잘 알려진 캐릭터 이름을
> 차단합니다. 반면 **동물 종류 자체(곰·햄스터·토끼)는 누구나 쓸 수 있는
> 소재**이고, 보호 대상은 특정 캐릭터의 이름과 실루엣입니다.

## 1-2. 그림체 — 같은 캐릭터를 어떤 붓으로 그리나

세 축이 서로 **독립**입니다. 섞이면 세트 통일감이 무너집니다.

| 축 | 무엇 | 세트 안에서 |
| --- | --- | --- |
| `CharacterSpec` | 누구인가 (종·색·이목구비) | **고정** |
| `DrawStyle` | 어떤 붓으로 그렸나 | **고정** |
| `seed` | 그때그때의 손떨림 | 컷마다 변함 |

카카오는 "단순하고 귀여운" 범위가 주류이고, **실사·극화체는 심사 탈락
가능성이 높다**고 알려져 있어 그 방향은 후보에 두지 않았습니다.

| 그림체 | 특징 | 쓰기 좋은 곳 |
| --- | --- | --- |
| `doodle` | 얇고 떨리는 선, 크림색 — 왼손으로 그린 듯 하찮고 귀여운 낙서체 | 현재 주류 트렌드 |
| `chunky` | 굵은 검은 선 + 또렷한 색 | 작게 줄여도 형태가 살아남아야 할 때 |
| `pastel` | 연한 갈색 선 + 파스텔 톤 + 볼터치 | 부드러운 감성 |
| `sticker` | 실루엣 바깥 흰 테두리 | 스티커 컷 느낌 |
| `mono` | 선화 위주, 채색 거의 없음 | 미니멀 |

```bash
# 한 캐릭터를 그림체별로 비교 (행 = 그림체, 열 = 표정)
kakao-emoticon-gen samples --mode styles --animal guineapig --character-seed 2

# 고른 그림체로 세트 생성
kakao-emoticon-gen generate --emotions "기쁨,슬픔" --backend sketch \
    --animal guineapig --character-seed 2 --draw-style chunky --fit canvas
```

## 2-1. AI 없이 바로 뽑아보기 (`sketch` 백엔드)

이 저장소는 위 고정 규칙을 **코드로 옮긴 절차적 렌더러**(`sketchgen.py`)를
포함합니다. 몸통·귀·팔다리를 **한 마스크로 합친 뒤 바깥 경계만 한 줄로** 긋기
때문에, 부품을 붙여놓은 '도형' 그림이 아니라 한 번에 그린 캐릭터로 보입니다.

```bash
# 캐릭터 후보를 같은 표정으로 비교
python -m kakao_emoticon_gen.cli samples --mode lineup --count 8 --out out/lineup.png

# 고른 후보(seed)로 32컷 표정 세트 미리보기
python -m kakao_emoticon_gen.cli samples --mode expressions --character-seed 5 \
    --cols 8 --cell 200 --out out/set.png
```

**캐릭터 정체성과 손떨림은 분리돼 있습니다.**

- `CharacterSpec` (종·색·비율·이목구비) → 32컷 내내 **고정**돼야 같은 캐릭터
- `seed` → 컷마다 **달라져야** 같은 사람이 그때그때 대충 그린 흔들림이 생김

세트를 만들 땐 `--character-seed`를 고정하고 `--seed`만 파생시키세요.

> ⚠️ `--fit canvas`를 함께 쓰세요. 기본값 `content`는 컷마다 내용물 경계에 맞춰
> 확대하기 때문에, **팔을 벌린 컷은 몸이 작아지고 웅크린 컷은 커져서** 32컷
> 통일감이 깨집니다.

이 출력물은 그대로 제출하기보다 **트레이싱용 러프**로 쓰는 것을 권합니다
(→ 아래 3번 항목).

### 움직이는 이모티콘 (움짤)

```bash
kakao-emoticon-gen animate --keyword 기쁨 --motion bounce \
    --animal hamster --character-seed 4 --seed 11 --out out/bounce.gif
```

모션 프리셋은 `bounce`(콩콩) · `wiggle`(좌우 흔들) · `nod`(끄덕)입니다.

핵심 규칙: **모든 프레임이 같은 `seed`를 쓰고 자세만 바뀝니다.** 프레임마다
seed를 바꾸면 선이 통째로 새로 그려져 화면이 지글거립니다(boiling line).
의도한 효과가 아니라면 피해야 합니다. `Motion`은 난수를 다 뽑은 *뒤에*
더해지므로 난수 소비 순서를 건드리지 않습니다 — 모션 0이면 정지 렌더와
픽셀 단위로 동일하고, 테스트가 이 불변식을 고정하고 있습니다.

> ⚠️ 움직이는 이모티콘의 카카오 제출 규격(프레임 수·용량·재생 시간)은
> 멈춰있는 이모티콘과 **다릅니다.** 현재 `validate`는 멈춰있는 이모티콘
> 기준만 검사하므로, 움짤 제출 전에는 공식 가이드를 직접 확인하세요.

## 3. 💡 이 화풍에서 특히 조심할 것

AI는 기본적으로 **"단정하게 그리려는" 경향**이 있어 표정이 밋밋해지고
명암이 들어갑니다. 그래서 `pen_doodle` 프리셋은 `dead flat eyes`, `gradient`,
`shading`, `symmetrical`, `polished`, `masterpiece` 같은 단어를 네거티브로
눌러두고, 프롬프트에는 `large bright highlights`, `manic`, `long midface`,
`clean flat fill`을 명시적으로 요구합니다.

그럼에도 몇 번 뽑아도 계속 깔끔하게 나온다면, 차라리 **AI 결과물을 러프
참고용으로만 쓰고 아이패드에서 얇은 펜 브러시로 30초 안에 빠르게 따라 그리는 것**이
훨씬 빠르고 확실합니다.

이 화풍의 본질이 "빨리 대충"이라 **오히려 그림 실력이 없어도 직접 그리기 가장 쉬운
스타일**입니다.

## 4. ✅ 제출 전 체크리스트

터미널에서 `python -m kakao_emoticon_gen.cli checklist`로도 볼 수 있습니다.

- [ ] 논란이 없을 법한 최신 유행어나 오래가는 밈을 활용
- [ ] 32컷 모두 같은 사람이 대충 그린 듯한 통일감 (선의 얇기·떨림 정도·낙서 텐션이 일정)
- [ ] 눈 스타일(초롱초롱/광기)이 컷마다 제멋대로 뒤섞이지 않았는지
- [ ] 눈과 입 사이(중안부)가 컷마다 들쭉날쭉하지 않은지
- [ ] 채색이 깔끔한 평면인지 (그라데이션·명암 금지)
- [ ] 참고 캐릭터와 실루엣이 겹치지 않는지
- [ ] 텍스트 없이 봐도 뜻이 통하는지 (논버벌 테스트)
- [ ] 손글씨 텍스트에 흰색 아웃라인 + 다크모드 가독성 확인

**자동 검사가 대신해 줄 수 없는 항목**은 위 목록의 통일감·실루엣 유사성·논버벌
테스트입니다. `validate`가 통과시켜도 이 세 가지는 반드시 사람이 눈으로 확인하세요.
